# Rutinler ve dikte türleri (Claude Design, 4 Ekim 2026)

Claude Design'ın "Berthier Rutinler tasarım incelemesi" devir paketi. Yalnız referanstır; `design-reference/` altındaki her şey gibi build, lint, tip denetimi ve Tailwind taramasının dışındadır.

- `Berthier Rutinler.dc.html`: tasarım dosyası (A1–A7 Rutinler, B1–B4 hatırlatma, C1–C4 dikte ve türler, D1–D3 değişen ekranlar, R1–R4 alternatifler, K6–K10 kararlar). Tarayıcıda `support.js` ile açılır.
- `devir/rutinler-devir.md`: Claude Code devir notu (veri, komutlar, model, kurallar, ölçüler, uygulama sırası).
- `shots/`: tasarım turunun ekran görüntüleri. `ref/`: tasarımın "önce" görselleri (aynıları `docs/design-review/` altında).
- `github.md`: Claude Design'ın eşitleme notu.

Pakette gelen `app/*.css` ve `public/icon-192.png` depodakilerle aynı olduğu için alınmadı.
